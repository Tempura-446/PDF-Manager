    Language

    Starter locales are automatic translations. Language packs also carry offline translation, OCR, and search-by-meaning models.

        Context-aware AI translation. Works 100% offline & free with local Ollama (http://localhost:11434/v1, e.g. qwen2.5:7b) or any OpenAI-compatible HTTPS API.

        Applies to both offline (NLLB-200 / Language Packs) and Smart AI translation.

        OCR (Make searchable)

        Default for Make searchable (OCR); you can still override it per file in the tool.

        Tries ONNX Runtime's DirectML provider on Windows; falls back to the CPU automatically if anything goes wrong.

        Right-click menu

        Right-click PDFs in File Explorer for ZPDF › Combine, Make searchable (OCR), Make smaller or Open, and pictures for Make a PDF with ZPDF. On Windows 11 they're under Show more options. This changes at once; it's for you only.

        Watch folders

        PDFs put in a watched folder are done one by one while ZPDF is open, each once. A note shows when a file is done or couldn't be. Files still downloading or being copied are left until they're complete.

          While ZPDF keeps watching, closing the window doesn't quit it. To quit for good: right-click its icon by the clock, or .

          Privacy

          The Recent list, where you were in each file, what ZPDF read from it, and the text kept by Search a folder.

          ZPDF's working files stay in its own folder, not the shared temporary one. They're deleted when a tool finishes, at the latest when ZPDF closes, and after a crash at the next start. Measurements and drawing scales you set are your work: they stay until you remove them.
